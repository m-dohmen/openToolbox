Sechs Werkzeuge, ein Gerüst

Jede dieser Demos ist eine einzige HTML-Datei — Anwendung und Datenbank zugleich. Kein Server, keine Installation. Herunterladen, doppelklicken, läuft.

Unterschiedlich sind sie nur in einer Datei: src/domain.js. Verschiedene Datenformen, verschiedene Farben, verschiedene Probleme.

Alle Daten sind erfunden. Die Beispiele veranschaulichen die Struktur solcher Werkzeuge — sie sind keine Rechtsberatung und kein Nachweis irgendeiner Konformität.
